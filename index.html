🔒 How to Signal a Stridulation Barrier Gate

Send signals from microservices, Docker containers, or CI/CD pipelines when a service finishes work. The barrier gate releases automatically when the required threshold or whitelist senders check in.

1. cURL / Webhook HTTP POST
curl -X POST "https://api.github.com/repos/YOUR_OWNER/YOUR_REPO/dispatches" \
  -H "Authorization: token ghp_YOUR_TOKEN" \
  -H "Accept: application/vnd.github.v3+json" \
  -d '{"event_type":"syncada_barrier_signal","client_payload":{"barrierKey":"gate-deploy-v1","sender":"auth-service","payload":{"status":"READY"}}}'
2. Syncada CLI Command
syncada barrier signal "gate-deploy-v1" --sender "auth-service" --payload '{"status":"READY"}'
3. Node.js / TypeScript SDK
import { Syncada } from 'terra-syncada';
const syncada = new Syncada({ githubToken: process.env.GITHUB_TOKEN });

// Signal barrier when service completes migration
await syncada.barrier.signalBarrier(barrier, 'auth-service', { authVersion: 'v2.1' });

🌰 How to Trigger a Nymph Task On-Demand

Trigger any Classic or Chrono Nymph Shell on-demand from your backend or terminal.

Syncada CLI Command
syncada task run task-midnight-backup

⏱️ How to Push Items into a Rate-Pulse Governor

Enqueue targets or payloads to be paced by the metronome governor to prevent HTTP 429 rate limit bans.

Syncada CLI Command
syncada governor push gov-openai-metronome --payload '{"input":"Hello world"}' --priority high
